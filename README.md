# 🏥 Smart Hospital Management System Powered by AI

A comprehensive hospital management system with integrated AI capabilities for enhanced patient care, appointment booking, and doctor-patient communication.

## ✨ Features

### 🤖 AI Assistant (AiDoc)
- **Intelligent Medical Companion**: AI-powered assistant that provides medical information and guidance
- **Appointment Booking**: Automated appointment scheduling powered by AI
- **24/7 Availability**: Round-the-clock support for patients

### 👨‍⚕️ Doctor-Patient Communication
- **Direct Chat**: Real-time messaging between patients and doctors
- **Appointment Management**: Easy appointment booking and scheduling
- **Patient Records**: Secure access to medical information

### 📋 Hospital Management
- **Patient Management**: Centralized patient information system
- **Appointment System**: Efficient scheduling and management
- **Doctor Directory**: Browse available doctors and their specialties

## 🛠️ Tech Stack

- **Frontend**: JavaScript (98.2%)
- **Styling**: CSS (1.4%)
- **Markup**: HTML (0.4%)

## 📋 Prerequisites

Before you begin, ensure you have the following installed:
- Node.js (v14.0.0 or higher)
- npm (v6.0.0 or higher)
- A modern web browser

## 🚀 Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/MTaha107/Smart-HMS-Powered-by-AI---FYP.git
   cd Smart-HMS-Powered-by-AI---FYP
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the application**
   ```bash
   npm start
   ```

4. **Open in browser**
   - Navigate to `http://localhost:3000` (or the configured port)

## 🎯 Usage

### For Patients
1. **Register/Login** to your account
2. **Chat with AiDoc** for medical guidance and information
3. **Book Appointments** directly through the AI assistant or manually
4. **Communicate with Doctors** via the chat feature
5. **Manage Your Profile** and medical records

### For Doctors
1. **Login** to your dashboard
2. **View Appointments** and patient information
3. **Respond to Patient Messages** in real-time
4. **Update Patient Records** as needed
